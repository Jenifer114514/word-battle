# 英単語バトル（WordBattle）— PeerJS P2P版

🔗 **プレイURL**: https://jenifer114514.github.io/word-battle/ （GitHub Pages）

鉄壁 改訂版の2,175語で、**PeerJS（P2P / WebRTC）**を使って別々の端末から同時対戦できる英単語4択クイズアプリです。

## 動作形態
- **`word-battle.html` 1ファイルで完結**（PeerJSライブラリ同梱・約260KB）。ブラウザで開くだけで動作し、サーバー不要です
- `node server.js` は配信用の補助（同じファイルを `http://<IP>:3000` で開けるようにするだけ）

## 🌟 ルーム対戦の流れ（P2P）
1. 全員が同じページ（HTMLファイル or 配信URL）を開く（**登録なしで「ゲストではじめる」でも参加可**）
2. ホストが「ルームを作成」→ **4桁コード**表示（PeerJS Cloudでシグナリング）
3. 友達がコード入力（4〜5桁）で参加 → WebRTCで**ホストと直接接続**
4. 開始で全員に同じ問題が同時出題（ホストが時間管理・採点）
5. 全員の回答が揃うか制限時間で解答表示 → 自動で次問 → 終了時にランキング
6. **各端末が自分の成績を自分の保存領域に記録** → 戦績・単語別統計・プレイヤー比較に反映

## 📢 公開ルーム（テンプレ部屋）
- ルーム設定画面に **HAFY1〜HAFY5 の固定コード部屋**を常設
- 各部屋の**人数と状態（待機中/対戦中/空き）をリアルタイム表示**（タップで空室ならホストとして開店・人がいればそのまま参加）

## 🔄 再戦
- 対戦終了後、ホストの結果画面に**「もう一度対戦（同じメンバーで）」**ボタンが現れる
- 押すと全員が自動で新しい問題の対戦を開始（スコアはリセット、結果もあらためて保存）
- 終了後もメンバーとの接続を60秒保持するので、その間なら再戦に誘導できる

## 🔌 通信状況と自動再接続
- ヘッダー左上に**通信状況（シグナルバー）**を常時表示（4本=P2P接続 / 点滅=接続中・再接続中 / 消灯=切断）
- 通信が切れても**自動で再接続**し、対戦の途中から復帰します（ホストは切断したゲストを待機扱いにし、復帰時に現在の問題と残り時間を再送）
- 対戦中に切断して**10秒戻ってこない場合は無回答扱い**で先に進みます（それ以降の問題も、戻ってくるまで待たずに進行）
- **ホストが消えたらメンバーが自動でホストを引き継ぎます**（同コードのルームがそのまま存続。途中の問題・スコア・全員の回答を復元し、出題中なら同じ問題を再送。ロビー中ならそのまま待機）
- 終了済みルームへの再接続では最終結果を再送して復元します

## 🔑 アカウント
- ユーザー名のみで登録（PINなし）／**登録しないゲスト参加も可能**（名前は「ゲスト+番号」を自動付与）
- 1端末1アカウント / 名前変更は7日に1回
- 戦績・単語統計は**各端末のブラウザ内**に保存（端末を変えると移行しません）

## 接続の仕組み
- シグナリング: PeerJS Cloud（`0.peerjs.com`・無料公開サービス）
- データ: WebRTC DataChannel（STUN: Google / TURN: Open Relay Project）
- ホストがオーソリティ：問題生成・採点・進行を担当。ゲストに正解は事前送信しない

## 開発
- `src/` … クライアント（head/CSS、PeerJS同梱、単語、コア、結果、ルームP2P、統計、プロフィール）
- `build.sh` … 連結して `word-battle.html` を再生成
- `server.js` … 静的配信のみ（LIVE PREVIEW / LAN共有用）
- `test/smoke.js` … クライアント＋PeerJSモックによるP2Pフローテスト / `test/server_test.js` … 配信テスト
